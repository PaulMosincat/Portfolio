Assembly / Game Logic

RISC-V Tetris

Created a Tetris game in RISC-V assembly focused on low-level systems programming and game logic implementation.

Overview

Developed core mechanics including movement, collision detection, and loop control while working within the constraints of the RARS simulator.

This project pushed the game logic closer to the hardware level, where each movement, board update, and control decision had to be represented through careful assembly structure.

What It Shows

  • Low-level game logic and structured assembly programming.
  • Memory management and debugging in RISC-V.
  • Persistence with complex control flow and simulator constraints.

Skills Used

RISC-V assembly, game loops, collision detection, board state, memory management, debugging, and control flow.
