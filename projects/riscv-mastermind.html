RISC-V Mastermind Game

Developed a console-based Mastermind game in RISC-V assembly using the RARS simulator.

Overview

Implemented random code generation, input validation, and feedback logic using low-level programming concepts.

The project required breaking a familiar game into small assembly routines and carefully tracking program state through registers, memory, branches, and simulator output.

What It Shows

  • Register management, branching, and memory operations.
  • Systems-level debugging and problem solving.
  • Ability to build interactive logic in a constrained environment.

Skills Used

RISC-V assembly, RARS, branching, memory operations, input handling, debugging, and structured low-level logic.
